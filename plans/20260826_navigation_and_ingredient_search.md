# 詳細画面の戻り固着と食材AND検索

## 目的

- 詳細画面から戻る際に画面が重なって操作不能になる問題を解消する。
- 複数食材を、空白の有無にかかわらずAND検索できるようにする。
- 漢字・ひらがな・カタカナなどの代表的な表記ゆれを吸収する。

## 原因と対策

- 原因: 詳細画面の独自左端スワイプが、Android／ブラウザ履歴の `popstate` と同時に画面を動かしていた。さらに遷移後に `swiping` クラスとインライン表示状態が残っていた。
- 対策: 詳細画面は独自左端スワイプを使わずAndroid標準の戻る履歴に委譲する。`navigateTo()` は全画面の一時状態を消し、古い遷移タイマーも画面を再表示できないようにする。`touchcancel` でも状態を解除する。

## 検索仕様

- `豚人参`、`豚 人参`、`ポーク・ニンジン` は、豚系と人参系を両方含むレシピだけを返す。
- 表記ゆれ辞書は豚肉、鶏肉、牛肉、ひき肉、人参、玉ねぎ、じゃがいも、キャベツ、大根、ねぎ、鮭、鯖、豆腐、卵などを含む。
- 辞書にない語もそのままAND条件として扱う。辞書の追加は `INGREDIENT_SEARCH_ALIASES` だけで行う。

## 検証

- `豚人参`: 両方入りは一致、豚だけ・人参だけは不一致: PASS
- `ポーク ニンジン`: 同じAND結果: PASS
- 詳細スワイプの競合回避・`touchcancel`・画面一時状態リセット契約: PASS
- JavaScript構文・`git diff --check`: PASS
