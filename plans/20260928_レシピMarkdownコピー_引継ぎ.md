# レシピMarkdownコピー

## 実施内容

- 詳細画面最下部に「レシピをコピーする」ボタンを配置した。
- コピー内容は保存済みレシピデータから生成する。倍率変更後の表示値ではなく、材料・手順の登録順と数量・単位・注記をそのまま使う。
- Markdownには概要、分類、分量、機器、調理方法、タグ、材料、手順、コツ、`source` のURLを含める。
- `source` が有効なhttp/https URLでない場合は、アプリの出典ボタンとMarkdownの `## 出典` をどちらも表示しない。

## 検証

- テスト用レシピで材料、手順、機器、出典URLを含むMarkdownになることを確認。
- 空欄と `javascript:` URLでは出典が含まれないことを確認。
- インラインJavaScriptのVMコンパイル、`git diff --check` が成功。

## 公開

- ユーザーから公開許可を受領済み。`docs/recipe.html`、今回と直前の記録・倍率変更のみを公開する。
- `docs/gas/Code.js` の既存変更は絶対に含めない。
