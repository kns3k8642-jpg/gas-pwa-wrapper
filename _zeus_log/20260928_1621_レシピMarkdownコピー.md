# 型07: レシピMarkdownコピー

## 依頼

詳細画面の下部にコピー用ボタンを置き、レシピ情報を忠実なMarkdownとしてコピーする。URLがある場合は含め、ホットクック向けアレンジ依頼や出典掲載に使う。実装後は公開する。

## 前提と完成基準

- 前提: コピー内容は画面の倍率表示ではなく、DBに保存されている材料・手順の値と順序を使う。
- 完成基準: Markdownにタイトル、基本情報、材料、手順、コツ、URLが含まれ、有効URLだけを出典として含める。コピーAPIと代替手段を実装し、静的契約テストを通す。

## 実施

- `docs/recipe.html` の詳細画面末尾へ「レシピをコピーする」を追加。
- JSON列を安全に読み、保存順の材料・手順・注記をMarkdownに整形する関数を追加。
- 有効な `source` だけを `## 出典` として出力。クリップボードAPIを優先し、非対応環境ではtextareaコピーへフォールバックする。
- 先行して未公開だった倍率0.25〜10.0倍の変更も同じ公開に含める。

## 検証

- JavaScript VMコンパイル成功。
- テストレシピの材料、手順、機器、出典URLを含むMarkdownを確認。
- 空欄・`javascript:` URLでは出典見出しが出ないことを確認。

- `docs/recipe.html`、STATUS、計画、Zeusログ、git-stateのみをコミットする。
- `docs/gas/Code.js` は作業前からの別変更なので除外する。
